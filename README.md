# Crimson Moon: Threads of the Weaver

An original 3D anime-style browser action game. Climb Mount Kurenai under a blood-red moon, master the Moonflow sword forms, and cut the Moonweaver's soul-threads to free the village below.

Built with React, Three.js and Vite. All art, models, music and SFX are generated in code - no third-party assets.
